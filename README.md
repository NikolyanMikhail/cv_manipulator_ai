## 🧠 Описание разработанного алгоритма (AI Brain)

Управление манипулятором построено на архитектуре, объединяющей сверточную нейросеть (YOLOv8) для восприятия и полносвязную нейросеть (PyTorch IKNet) для расчета обратной кинематики.

Алгоритм реализован в виде ROS 2 узла (`ai_brain_node`) и работает на частоте 33 Hz, обеспечивая плавность и точность движений.

### 1. Конвейер Компьютерного Зрения (CV Pipeline)
* **Детекция объектов:** Кадр с камеры передается в модель YOLOv8. Из массива bounding boxes извлекаются координаты (x, y) найденных красных кубиков.
* **Target Lock (Захват приоритетной цели):** Для решения проблемы "Буриданова осла" (множество целей в кадре), алгоритм по теореме Пифагора вычисляет Евклидово расстояние от оптической оси камеры до каждого кубика. Робот жестко фиксируется на ближайшей цели (`TARGET LOCKED`), игнорируя остальные, что исключает метания манипулятора.
* **Dynamic Bin Masking (Защитный визуальный щит):** Исключена реакция на уже отсортированные объекты. С помощью цветового фильтра HSV алгоритм находит желтую корзину и динамически накладывает на этот сектор кадра абсолютно черную маску (вплоть до верхней границы экрана). Это защищает систему от ложных срабатываний даже при образовании высоких "башен" из складированных кубиков в корзине.

### 2. Кинематика и защита оборудования
* **Shifted Singularity (Защита от скручивания):** Для предотвращения перекручивания сустава базы (и имитации защиты внутренних кабелей реального робота) внедрены программные концевики. Точка перехода $\pm\pi$ (сингулярность) математически смещена в слепую зону (корзину). Робот плавно сканирует сектор от $1.57$ до $-4.71$ рад.
* **Extreme Close-Quarters:** Диапазон захвата IK-математики расширен. Робот способен забирать кубики как на краю стола (до 35 см), так и в экстремальной близости к собственному основанию (до 6 см).

### 3. Машина состояний (State Machine)
Логика принятия решений разбита на жесткие состояния:
1. `SCAN` — Патрулирование рабочей зоны.
2. `ALIGN` — "Танковое наведение" базы и выпрямление стрелы для устранения ошибки (error < 0.015).
3. `PLUNGE_SETUP` / `FINE_ALIGN` — Снижение высоты и точная доводка над целью.
4. `BLIND_DROP` / `SETTLE` — Экстренное пикирование (до Z = 0.005) и стабилизация колебаний.
5. `HYDRAULIC_PRESS` / `HOLD` — Сжатие захвата с удержанием усилия.
6. `LIFT_HIGH` / `MOVE_TO_BIN` / `BOMB_DROP` — Подъем на безопасную высоту, кратчайший перелет к корзине и сброс.

## 🚀 Установка и Запуск

**Требования:**
* Ubuntu 22.04 + ROS 2 Humble
* Python 3.10+ (`torch`, `ultralytics`, `opencv-python`, `cv_bridge`)

**Сборка проекта:**
```bash
cd ~/robot_ws
colcon build --packages-select cv_manipulator_task
source install/setup.bash

1 терминал: Запуск симуляции (Gazebo): ros2 launch cv_manipulator_task start_gazebo_smart.launch.py
2 терминал: Запуск зрения робота (RQT): ros2 run rqt_image_view rqt_image_view
3 терминал: Запуск ИИ ("Мозг"): ros2 run cv_manipulator_task ai_brain_node
